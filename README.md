# Agua Santa Expediciones

**Estudiante:** Navas Cabrera Guido Bayron
**Destino turístico asignado:** Baños de Agua Santa – Tungurahua
**Asignatura:** Diseño de Sitios Web
**Institución:** Universidad Técnica Estatal de Quevedo (UTEQ)

## Descripción del proyecto

Sitio web de "Agua Santa Expediciones", una agencia de turismo ficticia especializada en promocionar
Baños de Agua Santa: sus cascadas (Pailón del Diablo, Manto de la Novia), la Casa del Árbol, las Termas
de la Virgen, el volcán Tungurahua y su oferta de turismo de aventura, gastronomía y cultura. El sitio
se desarrolló como examen práctico de la unidad de HTML5, CSS3, Git y GitHub, y está publicado mediante
GitHub Pages.

El proyecto tiene cinco páginas: inicio, lugares turísticos, servicios/paquetes, nosotros y contacto/
reserva, todas enlazadas por un menú de navegación común y construidas exclusivamente con HTML5 y CSS3.

## Tecnologías utilizadas

- HTML5 (estructura semántica: `header`, `nav`, `main`, `section`, `article`, `figure`, `footer`)
- CSS3 (Flexbox, CSS Grid, Box Model, pseudo-clases `:hover`/`:focus`, `@media`)
- Formulario HTML5 con validación nativa (`required`, `type="email"`, `type="date"`, `type="tel"`,
  `type="number"`, `select`)
- Git y GitHub
- GitHub Pages
